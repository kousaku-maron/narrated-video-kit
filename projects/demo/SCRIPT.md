# 動画制作デモ｜台本

この動画のゲーム画面は架空のサンプルです。音声と画面の対応を確認するための台本です。発話文を変える場合は、`project.json` の `narration.text` と音声ファイルも揃えます。

のそ爺固有の台詞はMIT対象外です。自分の動画を作る場合は、自分のキャラクターの台詞に書き換えてください。詳細は [ライセンス方針](../../LICENSING.md) を参照してください。

| 順番 | 場面ID | 音声・表示 |
| --- | --- | --- |
| 1 | `opening` | 「ようこそ。これはゲーム紹介動画を組み立てるための見本じゃ。」背景に導入タイトルを表示。 |
| 2 | `chapter-assets` | 無言。背景の上に「背景と音声」の章タイトルを表示。 |
| 3 | `background-and-voice` | 「背景には画像も動画も使える。声と字幕を重ねると、紹介の土台ができるぞ。」背景、のそ爺、発話字幕を表示。 |
| 4 | `image-inset` | 「見せたい場面では、画像を中央に大きく置く。話している内容が、ぐっと伝わりやすくなるんじゃ。」架空のゲーム画像を中央に表示。 |
| 5 | `chapter-finish` | 無言。「仕上げ」の章タイトルを表示。 |
| 6 | `finish` | 「章の見出しで話題を区切り、最後に締めの画面を置く。さあ、おぬしの動画も作ってみるのじゃ。」 |
| 7 | `end-card` | 無言。「次は、あなたの動画を」の締め画面を表示。 |

音声は AivisSpeech の「ろてじん（長老ボイス）」、話速 1.15 で生成したものです。字幕は発話文から作ります。章タイトルの間は音声を入れず、画面を読む時間にしています。
