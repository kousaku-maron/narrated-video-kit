# デモ素材の出典

| 素材 | 出典・作成方法 |
| --- | --- |
| `images/cover.svg` | このリポジトリ用に作成した抽象背景。 |
| `images/sample-gameplay.svg` | このリポジトリ用に作成した架空のゲーム画面。実在するゲームのスクリーンショットではありません。 |
| `footage/sample-motion.webm` | `../scripts/generate-footage.sh` で `cover.svg` に緩やかな動きを付けた無音の8秒映像。 |
| `audio/music/sample-ambient.wav` | `../scripts/generate-music.py` で生成した12秒のオリジナル音源。動画ではループ再生。 |
| `audio/narration/voice-01.wav` ～ `voice-04.wav` | `SCRIPT.md` の発話文を AivisSpeech「ろてじん（長老ボイス）」で生成。話速 1.15。 |

のそ爺のアバターはリポジトリ共通の `pelsona/nosojii/avatar/` を参照します。声には [ろてじんのモデル利用条件](https://hub.aivis-project.com/aivm-models/696c98a2-c0b7-4fe7-8cf2-c7e9b8a9bd82) が適用されます。各素材のMIT適用範囲は [ライセンス方針](../../../LICENSING.md) を参照してください。
