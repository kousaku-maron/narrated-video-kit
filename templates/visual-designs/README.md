# タイトル・サムネイルのデザイン部品

動画の構成は各動画テンプレートで決め、サムネイルは企画と素材に合わせて次の型から選ぶ。作品固有の文言・日付・画像は引き継がない。

| 型 | 向いている内容 | 原稿 |
| --- | --- | --- |
| 体験レビュー | 左上のチップ、左下の二段見出しと体験の根拠、右上のロゴ、右下のアバター | [レビュー型](../indie-game-review/thumbnail.html) |
| セール・複数作品紹介 | 右寄せの白い大見出し、色付きチップとアクセント線、本数・期間 | [セール型](../steam-sale-picks/thumbnail.html) |
| 告知・期間 | 上部のキービジュアル、下部の大きな主張、補足・開催期間、右下のアバター | [告知型](thumbnail-announcement.html) |

告知型はARC Raidersの制作で採用した配置を、別の作品にも使えるようにしたもの。独立した動画構成テンプレートではない。冒頭タイトルや章Transitionの表示方法は、使用する動画テンプレートの `VISUALS.md`・`TRANSITIONS.md` に従う。

## 告知型を使う

新規プロジェクトで、`thumbnail-announcement.html` を `projects/YYYYMMDD-name/publish/thumbnail.html` にコピーする。既存の原稿がある場合は上書きせず、試作を `work/` で比較して採用版を決める。

- 背景は `assets/images/thumbnail-bg.png`、アバターは `assets/images/thumbnail-avatar.png` を出発点とし、実際のファイル名に合わせてHTMLの相対パスを変更する。アバターが不要なら `.avatar` と `.avatar-glow` の要素を削る。
- `{{短い前置き}}`・`{{最も伝えたい一言}}`・`{{補足や開催期間}}` を差し替える。日付を入れる場合は公式情報と確認時点を記録し、公開予定・開催済みなどの時制を合わせる。
- `:root` の色・文字サイズ・背景の焦点位置を調整する。上部画像は縦横比を保って切り抜く。顔・ロゴ・主題が切れるなら焦点位置や画像を見直す。
- 主文と補足はアバターより左に収める。長い場合は文言を短くし、それでも必要なら文字サイズを調整する。作品名が背景で読めなければ前置きなどに入れる。
- 1280×720で書き出し、320×180でも主文と日付を確認する。白文字・黄色などの初期色は固定せず、作品の絵と背景の明るさに合わせる。

採用版の `thumbnail.html` と `thumbnail.png` は `publish/`、試作・旧版・確認用画像は `work/` に置く。使った画像の出典は `assets/SOURCES.md`、採用理由と文言は `publish/PUBLISH.md` に残す。
