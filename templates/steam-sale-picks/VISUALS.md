# セール紹介｜映像・レイアウト

今回の作品に合わせて文言・色・素材・尺を調整する。最終的な場面設定は `project.json` が基準。

## 冒頭タイトルとサムネイル

- 背景には紹介作品から選んだトレーラーを流す。冒頭とまとめで使う作品・区間を決め、映像の見せ場を文字で隠さない。
- タイトルは右寄せの大きな白文字。右側に薄い半透明の黒を重ね、背景映像も見せる。左上にセール名・企画テーマの色付きチップ、右側にアクセント線、日本時間の開催期間を置く。冒頭の語りの間はタイトルを表示する。
- サムネイルは同じ文字の階層と色を使う。必要なら文字を短くし、字幕や細かな説明を入れない。1280×720で作り、320×180で読みやすさを確認する。
- `intro-title` は次のように `project.json` の `overlays` で文言を指定する。短い文言を選び、レンダーした静止画で収まりを確認する。

```json
{
  "type": "intro-title",
  "text": "{{企画の主題}}",
  "badge": "{{セール名}} / {{ジャンル}}{{作品数}}選",
  "eyebrow": "{{英語のセール名と年}}",
  "line1": "{{視聴者の目的}}",
  "line2": "{{ジャンル}}ゲーム",
  "count": "{{作品数}}選",
  "periodLabel": "{{セール名}}開催期間",
  "periodText": "{{開始 M/D H:MM}} ― {{終了 M/D H:MM}}（日本時間）",
  "accentColor": "#f05a2a"
}
```

`text` はオーバーレイ設定上の識別用文字列で、見た目の文言は他の各項目を使う。長いセール名やジャンル名は、文字がチップ・右枠からはみ出さないよう短くする。

## 作品紹介

1. **背景**：話している作品のトレーラーを全面に流す。基本はトレーラー音声をミュートし、ナレーションとBGMが聞こえる音量にする。映像の採用区間と出典を `assets/SOURCES.md` に残す。
2. **左上チップ**：一行目に作品名、二行目に確認済みの日本向け価格。通常価格のみなら `￥{{額}}`。確認済みの割引なら通常額を取消線で示し、販売価格と割引率を続ける。「通常」「セール」の文字、矢印、確認日はチップに載せない。未発売は「未発売」、価格不明は「価格不明」とする。
3. **選びどころ**：確認済み割引は冒頭で「今は○%OFF、○円で遊べるぞ」と語り、音声・字幕・チップの数値を揃える。その後は映像の内容とナレーションが対応するようにする。特殊な注意点だけ別テロップを使う。
4. **余韻**：語りの直後に同じトレーラーを短く見せ、次の無声トランジションに移る。

価格チップの例:

```json
{
  "type": "label",
  "text": "{{作品名}}",
  "price": {
    "status": "sale",
    "regularYen": "{{通常価格の整数へ置換}}",
    "currentYen": "{{販売価格の整数へ置換}}",
    "discountPercent": "{{割引率の整数へ置換}}",
    "region": "JP",
    "sourceUrl": "{{Steam公式app URL}}",
    "verifiedAt": "{{YYYY-MM-DDTHH:mm:ss+09:00}}"
  }
}
```

`regularYen`・`currentYen`・`discountPercent` は文字列ではなく整数に置換する。`sale` は確認済み割引専用。`regular` では `currentYen` と地域・出典・確認日時を設定し、`discountPercent` は省く。`unreleased` / `unknown` では金額・割引率を設定しない。価格の根拠日時は `notes/SALE_CHECK.md` とデータに保持し、画面には出さない。

価格ラベルに `meta` / `discount` を重ねない。割引紹介の `narration.text` は数字の価格文を含め、`speechText` は同じ金額・率を表す読みを使う。誤読を直すため、作品の辞書で円額をひらがなへ置換してよい。音声素材に生成時の `narrationText`・`speechText`・`sha256` を登録する。[音声生成](../../speech/README.md)のJSONを `project -- add --voice-metadata` で取り込む。`check` は発音用の数詞も数値として照合し、価格・率・原稿・音声の生成メタデータとWAVハッシュを確認する。実際の発音と字幕のタイミングは試聴で確認する。

同じ作品の紹介を複数場面に分けてチップを保持する場合だけ、後続のラベルに `announcePrice: false` を付ける。冒頭場面では省略または `true` にして価格を読み上げる。

## 作品・セクション間のトランジション

- 本編の作品間と任意の個人パートの入口に、次の章で使うトレーラーを背景にした無声場面を置く。白い枠と白い見出しを中央に約2.4秒表示し、前後は短くフェードさせる。
- トランジションにはナレーション・字幕・トレーラー音声を入れない。BGMは前後と連続させる。`soundtrack.muteDuringTransitions` は `false` とする。
- 作品の主見出しは作品名とし、補助行に `02 / {{作品数}}` のような作品番号を付けられる。個人パートは日本語の見出しだけにし、`meta: "SECTION"` は設定しない。
- 個人パートで複数作品を話すなら、話している作品のトレーラーへ背景を切り替え、左上チップの見出しの下に作品名を表示する。
- トランジションから紹介本編へ移る時も、同じ背景映像を続ける。例えば元動画の2秒地点から2.4秒の見出しを見せたら、本編は4.4秒地点から始める。同じ開始位置に戻さない。`backgroundCuts` を使う場合も先頭カットにこの続きを指定する。尺を変えたら再生位置も合わせ、ループ素材は元動画の長さを考慮する。

冒頭から最初の作品へは直接つなぐ。締めの入口にもトランジションは置かない。2作品目以降の見出しから紹介本編へつなぐ場面の例（`scenes` に追加する2場面）:

```json
[
  {
    "id": "transition-game-02",
    "durationSeconds": 2.4,
    "background": {"asset": "trailer-game-02", "trimStartSeconds": 2, "volume": 0, "loop": true, "fit": "cover"},
    "overlays": [{"type": "transition", "text": "{{作品名}}", "meta": "02 / {{作品数}}"}]
  },
  {
    "id": "game-02",
    "background": {"asset": "trailer-game-02", "trimStartSeconds": 4.4, "volume": 0, "loop": true, "fit": "cover"},
    "narration": {"asset": "voice-game-02", "text": "{{読み上げ文}}"},
    "overlays": [{"type": "label", "text": "{{作品名}}", "price": {"status": "unknown"}}]
  }
]
```

## 画像を追加する場合

まず背景トレーラーだけで内容が伝わるか確認する。必要な場合だけ候補画像そのものを投稿者に見せ、表示する章・おおよその開始と終了・採用理由を示す。確認された画像だけ `project.json` の `inset` や `insetSegments` に入れる。同じ話題で一枚で足りるなら切り替えない。画像は字幕・価格チップ・アバターを隠さない位置に置く。

特定の敵・場所・機能を示す素材は、公式説明と元動画の時刻・音声で被写体を確認する。画面に写っていることと説明だけされていることを区別し、照合根拠を `notes/` に残す。

## 試写

- 冒頭のセール名、開催年、日本時間の開始・終了、作品数が読み取れる。
- 作品名と価格が背景の明暗に左右されず読める。取消線・販売価格・割引率が明確で、音声・字幕も同値。
- 全トランジションで見出しを読み切れ、BGMが途切れず、ナレーションは入らない。
- 見出しから本編へ移っても背景映像が巻き戻らず、同じ動きを繰り返さない。
- 冒頭と締めの入口にトランジションがない。
- 完成映像、字幕、投稿文、サムネイルの作品数と時制が一致する。
