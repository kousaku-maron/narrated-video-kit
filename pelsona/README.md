# キャラクター管理

このリポジトリでは、語り手を `pelsona/<キャラ名>/` ごとに管理します。`pelsona` と `PELSONA.md` は、このプロジェクトで使うディレクトリ名・ファイル名です。

```text
pelsona/
  <キャラ名>/
    PELSONA.md       # 口調、性格、語りの方針、使用する声
    avatar/           # 立ち絵、口パク用の透過画像、プレビュー
```

`<キャラ名>` には英小文字・数字・ハイフンの短い名前を使います。表示名は日本語でもよく、`PELSONA.md` に記載します。新しい語り手を増やすときは、同じ形のフォルダを追加してください。

`avatar/` には、口のない立ち絵と口の状態別 PNG を同じキャンバス寸法で置きます。動画で重ねる際は位置と大きさをそろえます。画像の制作経緯や利用条件は `avatar/README.md` に記録します。

ここにある画像はキャラクターの原本です。Remotion へ組み込むときは、対象動画のアセットとして読み込むかコピーします。現時点ではフォルダへ置くだけで動画に自動表示される仕組みはありません。

同梱の「のそ爺」はMIT対象外です。デモの確認以外で使う場合の条件は [nosojii/RIGHTS.md](nosojii/RIGHTS.md) を確認してください。
